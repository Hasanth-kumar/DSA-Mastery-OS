Returns `dayKind`, `phase` (pin / consolidation-day / block / mixed / consolidation-loop / idle), `blockTopicId` + block progress, `resolveTopicId` (consolidation day), up to 2 `picks` (problem, topic, `revealPattern`, role: pin / block / basic / pool / transfer / consolidate), `why`, `openTopicIds`, `consolidating` and every topic's pass. Not wired or exported yet (P7.5).
- How the rules read (for review):
  - **No new state.** A non-basic pattern is *introduced* once it has an attempt or is at pass ≥ 1. Its *block* is min(4, max(2, its pass-1 size)) problems, Easy first, and is done once that many of its problems are covered. A topic covered only by an import (Bit Manipulation, 1 of 9, no attempts) is not introduced, so it doesn't start a block out of order or take a cap slot.
  - **Open** = below pass 1 and (a basic, or introduced). Today: Sliding Window, Sorting + Two Pointers, Hashing + Set/Map, Counting / Frequency Map, Binary Search, String Matching.
  - **DP (1D) exemption** (D13): it may start while the cap is full; once started it counts as open like any other.
  - **Basics offer** (D13): while a basic is below pass 1, one of its remaining pass-1 problems is in the picks, hidden: the second slot on a block day, the first on a mixed day. It rotates to the least recently practised basic. Nothing is counted, so a skipped day offers the same single problem again.
  - **Mixed composition**: basics offer, then pass-1 problems from other open patterns whose block is done (least recently practised first), then at most one transfer problem (unseen Easy/Medium from a pattern at pass 1 that still owes its P7.3 transfer), then other basics. Two picks at most (D12). A pass-1 problem from an open pattern comes before the transfer check.
  - **Consolidation loop**: once all 21 core patterns are at pass ≥ 1, no introductions; picks go to basics and core below pass 2, lowest pass first, basics first, then the order; a hard prerequisite below pass 2 is served first (recursively). Pass-1 topics get unseen problems (the transfer that pass 2 needs); their help-needed problems come back through re-solves, not picks.
  - **Addition**: when basics and core are all at pass 2, the exposure loop resumes with the Later patterns (the plan doesn't say what happens then; without it the selector would go idle).
  - **Mixed-day `why`** never names a pattern: "Mixed practice: N patterns still need a first pass." / "… a clean cold solve." / "Mixed practice: 2 re-solves from one pattern are overdue, so today starts with one."
